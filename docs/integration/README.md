# Integration

Everything the three systems share and agree on together: the setup guide for the shared stack, meeting notes, and the contracts between systems (auth roles, gateway routes, vehicle status, notifications, the mobile app).

Big decisions become suite specs in `docs/specs/_root/`. This folder holds the working material around them.

| File | What it is |
|---|---|
| [setup-guide.md](setup-guide.md) | How to run the shared stack and plug your system into it |
| [web-login.md](web-login.md) | How a system's web app joins the shared web login: the session routes, the boot sequence, Switch system, sign out (spec 0007) |
| [shared-repo-changes.md](shared-repo-changes.md) | What changed in welinc-auth and welinc-web-portal this term, and what is planned |
